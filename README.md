SQL Data Analysis using Python and SQLite is a beginner-friendly data analytics project developed as part of DecodeLabs Data Analytics Project 3.

The project focuses on analyzing business data through SQL queries to extract meaningful information and generate useful business insights. It uses a sample dataset containing employee records and sales transactions, stored in an SQLite relational database.

Python is used to connect to the database, execute SQL queries, display results, and export reports into CSV files.

The project demonstrates important SQL concepts, including SELECT, WHERE, ORDER BY, GROUP BY, HAVING, INNER JOIN, and aggregate functions such as COUNT(), SUM(), and AVG(). It also includes monthly revenue analysis, product category comparisons, regional sales analysis, and percentage contribution calculations.

Through these queries, the project identifies total employees, sales transactions, overall revenue, average employee salary, the highest-revenue product category, and the leading sales region.

**Technologies Used:** Python, SQL, SQLite, and CSV.

**Key Learning Outcomes:** SQL querying, data filtering, sorting, grouping, aggregation, relational database management, data analysis, and business intelligence.

This project demonstrates how SQL and Python can work together to transform structured business data into meaningful information that supports data-driven decision-making.

**Note:** The dataset is created for educational and demonstration purposes and does not represent actual company records.
